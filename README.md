# Gourav Chandra - Portfolio

Welcome to my professional portfolio repository. This project showcases my expertise in web development, data analytics, and business automation, specifically tailored for e-commerce and enterprise operations.

## Overview

This portfolio is built using modern web technologies to provide a fast, responsive, and accessible experience. It highlights my core capabilities, including:

- **E-Commerce Architecture:** Building and managing scalable Shopware infrastructures, deploying high-converting landing pages, and optimizing multi-regional product pages.
- **Pricing Strategy & Modeling:** Developing dynamic pricing models for global markets and leveraging competitor analysis.
- **Business Intelligence:** Designing executive-level KPI dashboards for comprehensive operational tracking.
- **Data Automation:** Streamlining backend operations through intelligent automation, Python/SQL pipelines, and API integrations.

## Tech Stack

- **Frontend Framework:** React 18
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite
